## Cómo elegir entre Cloud y Local

| Factor | Cloud | Local |
|---|---|---|
| Empresa sin equipo IT robusto | ✓ | — |
| Necesita datos en Paraguay | ✓ (hosting PY) | ✓ (en su red) |
| Regulación BCP banca dura | ⚠️ aceptable | ✓ **preferido** |
| Presupuesto inicial limitado | ✓ | — (inversión hw) |
| Pensamiento a 5 años (TCO) | — | ✓ (perpetua gana) |
| Crecimiento rápido de activos | ✓ | ✓ (ambos ilimitados) |
| Infraestructura crítica | — | ✓ |
| Cooperativa financiera mediana | ✓ | ⚠️ |
| Ministerio / gobierno nacional | — | ✓ |
| Retail / logística / e-commerce | ✓ | — |

**Regla comercial**:
- Ticket anual proyectado < PYG 200M → **Cloud**
- PYG 200-600M → **mostrar ambos**, cliente decide
- > PYG 600M → **Local** (mayor margen + TCO favorable)
- Regulación banca/gobierno/crítica → **siempre Local**
