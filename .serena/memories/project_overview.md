# KRYON - Project Overview

## Purpose
KRYON is an open-source Autonomous Cybersecurity Intelligence Platform for building and deploying AI agents specialized in cybersecurity operations.

## Key Features
- **Autonomous Agents (Terminator Units)** - Pre-built agents for pentesting, forensics, and security research
- **Multi-Model Support** - Works with 300+ LLMs (GPT-4, Claude, DeepSeek, Llama, Ollama)
- **Security Tools Integration** - Native integration with nmap, metasploit, nuclei, and 50+ security tools
- **Agent SDK** - Build custom security agents
- **Swarm Operations** - Deploy multiple agents in parallel

## Use Cases
- Automated penetration testing
- Bug bounty hunting
- CTF competitions
- Security research and education
- Incident response and forensics
- Vulnerability assessment

## Tech Stack
- **Language**: Python 3.10+
- **Build System**: Hatchling
- **Package Manager**: UV
- **AI Framework**: LiteLLM, OpenAI SDK
- **Key Dependencies**: pydantic, rich, prompt_toolkit, mcp, paramiko, flask
